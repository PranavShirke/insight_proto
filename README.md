# InsightIQ 🚀

**Social Intelligence Dashboard** — A premium, high-performance analytics platform for modern creators.

![InsightIQ Dashboard](https://i.imgur.com/your-image-here.png)

## Overview

InsightIQ is a Next-Gen social media analytics dashboard designed with a **Crystal Glass** aesthetic. It provides creators with real-time insights, viral predictions, and AI-powered content strategy tools.

### Key Features

*   **📊 Modern Dashboard**: Real-time stats with glassmorphism UI, gradient charts, and a floating dock sidebar.
*   **🔮 Viral Predictor**: Upload content to get a predicted virality score before you post.
*   **🤖 Ask AI**: Natural language chat interface to query your data (e.g., *"When is the best time to post?"*).
*   **📡 Trend Radar**: Visual radar scanner to detect emerging trends in your niche.
*   **🧬 Content Comparison**: Detailed breakdown of Reels vs. Carousels vs. Static posts.
*   **📝 Reports**: Exportable executive summaries and growth strategy PDF reports.

## Tech Stack

*   **Framework**: React + Vite
*   **Styling**: Tailwind CSS + Framer Motion
*   **Charts**: Recharts
*   **Icons**: Lucide React
*   **Routing**: React Router DOM

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

*   Node.js (v16 or higher)
*   npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/insight-iq.git
    cd insight-iq
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

4.  Open your browser at `http://localhost:5173`.
